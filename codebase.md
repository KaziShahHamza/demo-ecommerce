# Codebase Overview

## Current state

This repository is a minimal demo repository used to test contributor and pull-request workflows. It does not currently contain an ecommerce application, runtime code, dependency manifests, tests, or build configuration.

## Repository layout

| Path | Purpose |
| --- | --- |
| `README.md` | Repository title and short introduction. |
| `notes.md` | Note recording the contributor-workflow demo contribution. |
| `demo.txt` | Plain-text fixture for the PR workflow test. |
| `.github/agents/codebase_explorer.agent.md` | Custom Copilot agent definition that instructs an agent to inspect the repository and maintain this overview. |

## Development and validation

No package manager, framework, executable entry point, test runner, or CI workflow is configured. Changes are currently limited to repository documentation and workflow fixtures.
