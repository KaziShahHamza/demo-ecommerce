# Demo Ecommerce

A minimal repository for testing contributor and pull-request workflows.

## Repository contents

- `demo.txt` — plain-text fixture used by workflow tests.
- `notes.md` — record of the demo contribution.
- `.github/agents/codebase_explorer.agent.md` — custom Copilot agent configuration.

## Project status

This repository does not currently contain an ecommerce application, runtime code,
dependency manifests, tests, or build configuration. It is currently limited to
documentation and workflow fixtures.

## Development

No setup or build commands are required. Review changes directly in the
repository and use the configured contributor workflow for validation.

## Getting Started

Clone the repository and create a feature branch from `main`:

```bash
git clone https://github.com/KaziShahHamza/demo-ecommerce.git
cd demo-ecommerce
git checkout -b my-feature
```

Commit and push your changes, then open a Pull Request targeting `main`.

## Contributing
1. Create a feature branch from `main`.
2. Commit your changes and push the branch.
3. Open a Pull Request targeting `main`.
